# Visit Flow – Visitor Management System

## Tech Stack

- React.js
- Vite
- Tailwind CSS

## Requirements

- Node.js
- npm

## Setup

Install dependencies:

```bash
npm install
```

Start:

```bash
npm run dev
```

The app will run at:

`http://localhost:5173`

## Technical Decisions

### React.js

React.js dipilih karena memudahkan pembangunan aplikasi yang dapat dibagi menjadi komponen-komponen tersendiri sehingga lebih mudah untuk dikelola dan bisa dipakai ulang jika perlu dikembangkan lebih lanjut.

## Limitations

- Hanya terdapat satu akun login
- Tidak ada data nama sales
- Tidak bisa menghapus data
- Data aktivitas yang bisa diubah hanya atribut status
- Tidak ada registrasi akun
